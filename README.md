# 🔢 Python Arithmetic Calculator

A simple menu-driven calculator built using Python that allows users to perform basic arithmetic operations such as addition, subtraction, multiplication, division, and more.

## 🚀 Features
- User-friendly menu interface
- Supports 7 arithmetic operations
- Handles division by zero errors
- Beginner-friendly code structure

## 🛠️ Tech Stack
- Python (Core Concepts)

## 📂 How to Run
1. Clone the repository
2. Run the file:
   python calculator.py
